# AI_fluencyTraining
# Day 1 – Agentic AI

## Topics

* Introduction to AI Agents
* Agent Components
* LLM and Tool Usage
* Basic Agent Workflow
* Environment Setup

## Programs

* `config.py` – Configures the LLM and environment.
* `tools.py` – Defines tools used by the agent.
* `agent.py` – Implements the basic AI agent.
* `check_setup.py` – Verifies the project setup.

## Goal

Understand the fundamentals of AI agents and build a basic working agent using an LLM and tools.

# Day 2 – Agentic AI

## Topics

* ReAct: Thought → Action → Observation
* Chain-of-Thought (CoT) Prompting
* Self-Consistency

## Programs

* `react_trace.py` – Traces the ReAct agent and tool calls.
* `cot_compare.py` – Compares answers with and without CoT.
* `self_consistency.py` – Runs multiple reasoning paths and selects the majority answer.

## Goal

Understand how ReAct, Chain-of-Thought, and Self-Consistency improve AI agent reasoning and tool usage.
